# ☕ Reboot Coffee

## 📌 Overview

**Reboot Coffee** is a full-stack web application developed to demonstrate modern web development skills. The project simulates a coffee and milk tea shop website with a strong focus on clean architecture, content management, and a polished user experience.

The application consists of a responsive frontend built with **Vue.js** and a robust backend powered by **Node.js**, **Express**, and **MongoDB**.
